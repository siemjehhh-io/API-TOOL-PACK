# PROJECT OVERVIEW
Name: WD Data Extractor
Tech Stack: React (Vite), TailwindCSS, `xlsx` (SheetJS) for parsing, and `lucide-react` for beautiful icons.
Architecture: Fully client-side. No backend database needed. The app reads a local Excel file, transforms the data based on specific rules, and provides a "Copy to Clipboard" button in a TSV/Spreadsheet-compatible format.

# DESIGN SYSTEM & VIBE
Create a modern, minimalistic, and professional UI. Use a calming, shaded, and slightly melancholic aesthetic. Think "Dark Mode" by default or a very elegant dark theme using slate, muted deep navy/blues, and soft gray text (e.g., bg-slate-900, surface bg-slate-800, accents with muted indigo). It should feel focused, quiet, and premium.
